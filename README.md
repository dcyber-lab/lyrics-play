# Lyrics Live

去现场听歌时用的歌词滚动网页：按 setlist 建歌单，进场前缓存好，现场跟着乐队滚动，偶尔点一下校准。

## 怎么用

1. 首页「预设歌单」里点导入，会在手机上从 LRCLIB 拉歌词（预设只存歌名/歌手/时长，在 `src/presets.js`）；或者新建歌单，从 [LRCLIB](https://lrclib.net) 搜歌，或者把整场 setlist 粘进「批量」里（每行一首）
2. 进场前在 Safari 里打开一次，「分享 → 添加到主屏幕」，之后离线也能用
3. 现场：**歌手开口时点那一行**，歌词就从这里开始走
4. 对不上了就再点当前在唱的那一行。两次点击间隔够长的话，会顺便学到乐队的实际速度（现场通常比录音室版快或慢几个百分点）
5. 细调用 `−½s` / `+½s`，⚙ 里可以手动调速度；🔒 锁住之后点歌词不会误触

没有时间轴的歌词（标「估算」）会按歌长均匀铺开，多点几下就能跟上。

## 同步原理

`src/lib/clock.js` 里的 `SyncClock`：歌词位置 = 锚点 + 经过的时间 × rate。每次点某一行就是一次观测，含义是“此刻唱到这里了”。两次观测之间的歌词时间差除以真实时间差，就是实测速度，按权重混进 rate。下面三种情况会忽略这次观测：跨度太短（误差大）、差得离谱（大概率是跳段或重复副歌）、中间暂停过（MC 时间会污染测量）。

## 开发

```sh
npm install
npm run dev      # 本地开发
npm test         # 单元测试
npm run build    # 输出到 dist/
```

推到 `main` 后，`.github/workflows/deploy.yml` 会自动部署到 GitHub Pages（需要在仓库 Settings → Pages 里把 Source 设成 GitHub Actions）。
